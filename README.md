# Cost Explorer

A lightweight cloud cost exploration dashboard built with Next.js, React, and Tailwind CSS. It lets users drill down through grouped spend data, explore clusters/namespaces/resources, and toggle between time windows.

## Features

- Interactive cost hierarchy drill-down
- Aggregate views by cluster, namespace, and resource
- Responsive table and chart views
- Animated loading and error states
- Light/dark theme toggle
- Data fetching via DummyJSON product feed as a mock cost dataset

## Tech Stack

- Next.js 14
- React 18
- TypeScript
- Tailwind CSS
- TanStack React Query
- Framer Motion
- Axios
